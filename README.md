# old-arduino-pingpong

An old version of a Ping Pong game for Arduino, made for learning C++.

This project was moved from my old account. It is kept here as an archive, unchanged.

## What is it

A simple Ping Pong game that runs on an Arduino board using a display, potentiometers and a button.

## How to run

1. Install the [Arduino IDE](https://www.arduino.cc/en/software).
2. Open the `.ino` file from the `pinpong_arduino_old` folder.
3. Select your board and port.
4. Click "Upload".

## Important note

The board I used for this project is modified and has an additional potentiometer. Because of this, the code may not work on a standard Arduino board without changes.
